🌿 Scientific NDVI & Classification Rules

                            

                                

                                    Formula
                                    NDVI = (B08 - B04) / (B08 + B04)
                                

                                

                                    Dense Canopy
                                    NDVI > 0.60
                                

                                

                                    Moderate Canopy
                                    0.40 ≤ NDVI ≤ 0.60
                                

                                

                                    Sparse Vegetation
                                    0.20 ≤ NDVI < 0.40
                                

                                

                                    Non-Forest / Bare / Water
                                    NDVI < 0.20
                                

                                

                                    Deforestation Alert Threshold
                                    ΔNDVI < -0.15
                                

                            

                        

                    


                    

                        
🛡️ Atmospheric Quality Masking (SCL)

                        

                            ForestWatch AI enforces pixel-level Scene Classification Layer (SCL) masking to prevent false deforestation alarms caused by atmospheric artifacts:
                        

                        

                            Class 3: Cloud Shadows (Masked)
                            Class 8: Clouds Medium Probability (Masked)
                            Class 9: Clouds High Probability (Masked)
                            Class 10: Cirrus High Altitude (Masked)
                            Class 11: Snow / Ice (Masked)
                            Classes 4, 5, 6, 7: Valid Land Surface (Retained)
